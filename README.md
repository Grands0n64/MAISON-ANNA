# Maison Anna

**The Art of Giving Flowers.**

A luxury floral storefront for romantic bouquets, signature arrangements and bespoke floral experiences.

## Preview
The storefront is a responsive static website in `index.html`. It includes a searchable 50-item collection, category filters, price sorting and product detail panels.

## Launch notes
- Catalogue prices are proposed product/commission prices, not supplier-verified quotations.
- Large commissions require a written scope, availability check, delivery assessment and signed quotation.
- Checkout and payment processing are not activated. Connect a supported payment provider and verified business contact details before accepting orders or payments.
- Product photography is loaded from Unsplash.
- GitHub Actions deployment is configured in `.github/workflows/deploy.yml`. Enable GitHub Pages with **Settings → Pages → Build and deployment → GitHub Actions** if it is not already enabled.
